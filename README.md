# SalesMate

Aplicación web multiproyecto con agentes de IA que ayudan en el proceso de
venta de varias empresas o actividades profesionales, conectándose a las
herramientas de cada proyecto (CRM, correo, calendario, llamadas, WhatsApp…).

- **Agente Outbound**: prospección, investigación, outreach personalizado y seguimientos.
- **Agente Inbound**: respuesta inmediata, cualificación, agendado y registro en el CRM.
- **Agente de Inteligencia** (fase posterior): señales de compra, cuentas calientes y optimización.

Inspirado en [Alta](https://www.altahq.com/).
